# Karel the Robot

My work from the Karel weeks of COSC 10001 at TCU. Karel is a robot that only knows four commands.

## How to Run
Open the folder in IntelliJ and run `karel-starter/run.ps1` in the terminal.

## What I Learned
* Karel has no `turnRight()`, so I built one using three `turnLeft()` commands.
* How to use basic Git commands (`git add`, `git commit`, `git push`) to save my work to GitHub.
